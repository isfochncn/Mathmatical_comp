## 从题面到模型的六张表

正式选模前，先把题面拆成六张小表。它们比立即搜索“高级模型”更能防止跑题。

| 表 | 要记录的内容 | 常见陷阱 |
|---|---|---|
| 任务表 | 每问的动词：解释、估计、预测、评价、设计、优化、检验 | 把“分析”误写成“排序”，把“建议”偷换成“预测” |
| 对象表 | 系统边界、主体、时间/空间尺度 | 把局部模型外推到整个系统 |
| 数据表 | 来源、变量、单位、粒度、缺失、异常、时间顺序 | 数据泄漏、单位不一、附件字段误读 |
| 变量表 | 已知量、待估参数、状态变量、决策变量、随机量 | 将不可控参数当决策变量 |
| 约束表 | 硬约束、软约束、逻辑约束、资源约束、边界条件 | 优化结果数值漂亮但不可执行 |
| 证据表 | 题目要求的指标、可用基线、可检验事实 | 只报最优值，不证明可信 |

然后画依赖图：上一问产生的哪些参数、预测或可行域会进入下一问。若各问完全割裂，通常值得重新检查题意。

## 一套通用工作流

1. **把任务改写成输入—输出。** 例如“制定方案”应明确输出时间、位置、数量或动作序列。
2. **定义成功。** 把“合理”“最好”“风险小”翻译为指标或偏序关系。
3. **先立最小基线。** 解析简化、均值预测、贪心、等权评分或现状策略都可作为参照。
4. **再加必要复杂度。** 只有当基线无法表示关键机制/约束时，才引入更复杂模型。
5. **选择求解器。** 根据变量类型、凸性、规模和时间选择精确算法、数值法或启发式算法。
6. **设计验证后再计算。** 事先写下要比较什么、怎样判定可靠，避免得到结果后才挑检验。
7. **闭环解释。** 将结果翻译回现实问题，并说明适用条件和失败情形。

## 常见模型主线

### 机理建模

适合存在守恒律、运动学、热传导、光学、几何或动力学规律的题。典型链条：机制假设 → 微分/代数方程 → 参数辨识 → 数值求解 → 边界与实验检验 → 控制/优化。

`[样]` 2019 A、2020 A、2022 A、2025 B 都属于这一主线。优秀论文往往先用物理关系缩小自由度，再优化；不是直接把所有变量扔给搜索算法。

### 统计分析

适合解释关系、检验差异、估计参数与不确定性。典型链条：数据审计 → 描述统计 → 假设/分布 → 模型估计 → 诊断 → 置信区间或效应解释。

`[样]` 2021 B 的多篇论文都研究催化剂组合与温度影响，但路线包括方差分析、非线性回归、PCA、逐步回归、BP 神经网络和均匀设计。共同底线是把因素、响应和交互作用说清楚。

### 预测—优化

先预测需求、价格、风险或状态，再将预测输入优化模型。必须处理预测误差，至少用情景、区间、鲁棒/随机优化或敏感性分析之一。

`[样]` 2023 C 和 2024 C 大量采用此链条。只把预测点估计塞入确定性优化，会把不确定性“藏起来”。

### 评价—排序

先构造指标体系，再标准化、赋权、聚合和排序。核心困难不是选 TOPSIS 还是 VIKOR，而是指标是否能代表题意、方向与量纲是否处理正确、权重是否可解释、排序是否稳定。

### 仿真—决策

当规则明确但解析解困难，可建立离散事件、蒙特卡洛、系统动力学或主体仿真，比较策略分布而非单次结果。仿真需要随机数设计、重复次数、置信区间和校准。

### 分阶段递进

将二维到三维、确定到随机、单主体到多主体、局部到全局逐级扩展。每一级解决新的题意困难，不是换模型名。2023 B477、2025 C023/C132 都体现了这种结构。

### 多模型交叉验证

用独立方法求同一关键量，或用简单模型校验复杂模型。前提是方法之间具有真正独立的信息/假设；两个仅更换优化器的相似结果不能完全证明模型正确。

## 模型选择决策表

| 任务与数据 | 优先考虑 | 何时升级 | 必做验证 |
|---|---|---|---|
| 小样本、有明确机理 | 方程、几何、贝叶斯/正则化回归 | 机理不足且有额外数据 | 边界、量纲、参数敏感性 |
| 中小样本解释关系 | 线性/广义线性、方差分析、混合效应 | 明显非线性或层级结构 | 残差、共线性、效应量、区间 |
| 时序预测 | 朴素季节基线、指数平滑、ARIMA/状态空间 | 长序列、复杂非线性、多变量 | 时间滚动验证，严禁随机泄漏 |
| 表格型分类/回归 | Logistic/线性、树模型 | 非线性和交互显著 | 独立验证、AUC/F1/校准与基线 |
| 连续/线性优化 | LP/QP/NLP 与成熟求解器 | 非凸、离散或黑箱目标 | 可行性、界、不同初值 |
| 组合优化 | DP、网络流、MILP、分支定界 | 规模太大或求解超时 | 小规模精确解、启发式重复运行 |
| 多目标优化 | 明确权衡、ε-约束、加权或 Pareto | 前沿复杂、变量离散 | 权重/偏好敏感性、代表方案解释 |
| 综合评价 | 可解释指标 + 等权/客观权重基线 | 存在明确偏好或模糊性 | 权重扰动、排序稳定性 |
| 规则复杂系统 | 离散事件/蒙特卡洛/主体仿真 | 主体交互和反馈重要 | 校准、重复、置信区间、极端情景 |

模型不是按“高级程度”升级，而是按题目中尚未被表示的结构升级。

## 最容易失分的逻辑问题

### 假设与后文脱节

列了“风速恒定”，模型却没有风速；或假设独立，却使用联合分布但不说明。解决办法是做“假设—公式—检验”三列映射。

### 目标函数偷换

题目要求总成本最小，论文却只最小化运输距离；题目要求风险与收益平衡，却先排序再拍脑袋分配。应说明代理指标为何等价或近似，并讨论偏差。

### 约束遗漏

特别留意整数性、逻辑互斥、容量、边界、时间先后、守恒和现实可操作性。求解后重新从原题逐条验约束，不要只相信求解器状态。

### 数据泄漏

使用未来数据预测过去、全数据标准化后再切分、重复主体跨训练测试集、用目标变量衍生特征。时序题按时间切，分组数据按主体切；预处理参数只在训练集拟合。

### 缺少基线

复杂方法的高准确率无法单独说明价值。与均值、上一期、等权、贪心、线性模型或现有规则比较，才能回答“复杂度是否值得”。

### 只报最优值

至少同时报告：关键决策变量、目标值、约束余量、运行稳定性、参数扰动结果。随机算法应报告多次运行分布，不只挑最好一次。

### 只做“形式化敏感性”

机械地把所有参数 ±5% 没有意义。优先扰动测量误差大、来自假设、对决策关键或不可控的参数，并解释决策在哪个阈值发生变化。

## 进阶观察：怎样形成自己的套路

可积累的是“结构化动作”，不是固定模型包：

1. 每题先做量纲、数量级和极端情形检查。
2. 每个复杂模型保留一个简单基线。
3. 每个随机/启发式算法预设重复运行和随机种子方案。
4. 每个预测模型预设与下游决策的误差接口。
5. 每个评价排序预设权重扰动与替代标准化。
6. 每一问写一句“本问输出将怎样服务下一问”。

## 开模前十分钟检查

- [ ] 每问的输出已写成变量、表格或方案形式。
- [ ] “最好/合理/风险”已有数学定义。
- [ ] 硬约束与软偏好已分开。
- [ ] 已建立至少一个简单基线。
- [ ] 已决定如何验证，而不是只决定如何求解。
- [ ] 选用的每个模型都解决一个具体困难。
