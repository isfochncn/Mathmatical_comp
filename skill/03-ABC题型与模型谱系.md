## 先说结论

`[样]` 2019—2025 的 A/B/C 并不存在“一个题号对应一种固定模型”。更稳定的规律是：题目把什么结构交给你——机理、数据、离散规则、不确定性或多目标——优秀论文就用什么工具表示它。

`[推]` 选题时可以用题号倾向估计工作量，但选模必须回到任务结构。把“A 题 = 微分方程、C 题 = TOPSIS”当作模板，容易忽略真正的约束和验证。

## A 题：常见特点与成功路线

`[样]` 近年 A 题多有清晰的物理、几何或工程机制。常见骨架：

> 建立坐标/状态 → 写出机理方程或几何判据 → 辨识参数 → 数值求解 → 设计控制或优化 → 用极限、误差或独立算法检验。

优秀做法：

- 先用机制减少需要搜索的变量；
- 分清连续模型与离散数值近似，并讨论步长；
- 把碰撞、遮蔽、有效区间等自然语言条件写成可计算判别式；
- 给出单位、边界条件、初始条件和数值误差；
- 最优化结果回代原方程/原约束。

常见误区：只展示三维图而不定义几何；直接调用 ODE 求解器不交代方程；用启发式算法掩盖可解析/可精确求解的结构。

## B 题：常见特点与成功路线

`[样]` B 题的结构变化最大，既有物理几何，也有游戏、生产决策、数据处理。比较稳定的能力是把规则和状态离散清楚。

> 明确状态与动作 → 写转移/几何/概率关系 → 构造可行策略 → 求解或仿真 → 比较基线和极端情形。

优秀做法：

- 对动态规划明确状态、阶段、动作、转移和边界；
- 对博弈说明参与者、信息、策略与收益；
- 对测量/定位题给独立几何路线或误差传播；
- 对抽样检验把置信度、样本量和决策损失连起来。

常见误区：状态定义遗漏历史信息；把期望最优当成每次都最优；仿真只跑一次；所谓博弈只有“竞争”字样，没有策略与均衡。

## C 题：常见特点与成功路线

`[样]` C 题近年更常出现真实表格数据、统计推断和运营决策，但 2022 C 是成分数据与分类，2025 C 又是临床检测时点与异常判定，不能简化为“评价题”。

常见骨架：

> 数据审计 → 描述/关系分析 → 预测、分类或评价 → 决策优化 → 不确定性与可解释性。

优秀做法：

- 先处理缺失、异常、分布偏态、时间顺序与组成约束；
- 根据因变量类型选择回归/分类/生存模型，而不是盲目套预测器；
- 预测模型与下游决策通过情景、概率或鲁棒项连接；
- 评价指标具有业务含义，权重与排序做稳定性分析；
- 结果不仅有总体准确率，还有类别不平衡、校准、误判代价或外部意义。

## 评价模型：适用条件与滥用边界

| 方法 | 适合什么 | 关键假设/代价 | 常见滥用 | 最少应补的验证 |
|---|---|---|---|---|
| AHP（层次分析法） | 有明确层级、专家偏好需要显式表达 | 主观判断；成对比较需一致 | 指标很多仍硬做矩阵；专家来源不明 | 一致性检验、专家/权重扰动 |
| 熵权法 | 希望按样本离散程度给客观权重 | 变异大被视为信息多，不等于更重要 | 把异常噪声当重要性；称其“完全客观” | 去异常、标准化替代、权重敏感性 |
| TOPSIS | 指标单调、需要距理想点的综合接近度 | 距离和标准化选择影响结果 | 指标相关性强；正负方向弄错 | 替代归一化、权重扰动、排序稳定性 |
| PCA（主成分分析） | 连续指标相关、需要降维或构造少数综合成分 | 线性、方差代表信息；成分未必有业务意义 | 直接把主成分当“好坏”；混入类别变量 | KMO/方差解释、载荷解释、稳定性 |
| 模糊综合评价 | 边界确实模糊且有合理隶属函数 | 隶属函数与规则带主观性 | 任何评分题都“模糊化” | 函数来源、参数扰动、与硬阈值比较 |
| 灰色关联 | 小样本、需比较序列形状接近性 | 对标准化与分辨系数敏感 | 把关联度写成因果或预测能力 | 分辨系数/标准化敏感性、外部对照 |
| VIKOR | 多准则折中，需要兼顾群体效用与最大遗憾 | 需解释折中参数和可接受优势 | 不解释参数，仅替代 TOPSIS | 参数扫描、排序条件与替代法比较 |
| 等权评分 | 指标意义相当、需要透明基线 | 忽略真实偏好差异 | 因“简单”而完全跳过 | 作为基线，与复杂赋权结果比较 |

`[推]` 评价题最强的答法通常不是再加一种赋权，而是证明：指标有效、权重可解释、排序在合理扰动下稳定，且排序与后续决策相连。

## 模型组合的三种合格关系

1. **串联分工**：预测需求 → 优化库存；聚类分组 → 分组建模。
2. **独立校验**：解析解与数值解；精确小规模解与启发式大规模解。
3. **逐级扩展**：确定性 → 随机；单目标 → 多目标；二维 → 三维。

相反，如果多个模型回答同一问却没有比较和选择标准，它们只是并排出现，不构成证据。

## 关于“评委偏爱”的可说与不可说

- `[官]` 可以说：公开规范强调论文规范、原创与创新审查、代码和结果一致性；全国评阅会讨论题意、关键点和可能方法并形成统一尺度。
- `[样]` 可以说：同题获奖论文方法多样，复杂算法和简单模型均有出现。
- `[推]` 可以说：任务驱动、链条连贯、关键量可解释、结果可验证，比追逐某个模型名称更稳妥。
- 不可说：评委固定偏爱 AHP/神经网络/遗传算法；用了黑箱一定扣分；模型越多越容易得奖。现有证据无法支持。

## 进阶观察

真正拉开差距的往往是“接口”：原始数据怎样成为参数，预测误差怎样进入优化，评价排序怎样转化为资源分配，仿真结果怎样反证假设。训练时应专门检查这些接口，而不只检查每个模型内部。
