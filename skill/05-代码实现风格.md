## 观察范围与边界

本章只观察 2012—2014 年 A/B/C 压缩包中的实现风格，不尝试完整复现实验，也不默认旧代码正确。压缩包仅作只读清单分析，未覆盖解压回 `good_paper/`。

样本包含 MATLAB、C++、Java、LINGO、SAS、Mathematica、Excel 与文本数据。旧环境、编码、依赖和数据路径可能已不可用，因此“有源码”不等于“今天可运行”。

## 从旧代码看到的共同问题

1. 文件名能按分问拆开，但不一定有一个总入口。
2. 参数常直接写在脚本内部，论文与代码难以逐项核对。
3. Excel 既作输入又作输出，容易混淆原始数据与中间结果。
4. 随机算法较少固定种子或汇总多次运行。
5. 路径、软件版本、依赖和运行顺序经常缺失。
6. 结果图可以生成，但未必自动保存生成该图所需的数据。

这些不是对具体论文正确性的判定，而是从现代可复现要求看出的风险。

## 当前比赛推荐目录

```text
support/
├─ README.md                 # 环境、入口、执行顺序、预计时间
├─ requirements.txt          # 或 environment.yml / 软件版本说明
├─ data/
│  ├─ raw/                   # 题目附件与自采原始数据，只读
│  ├─ external/              # 来源、日期、链接或说明
│  └─ processed/             # 可由脚本再生
├─ src/
│  ├─ common/                # 公共函数
│  ├─ problem1/ ...          # 按分问组织
│  └─ run_all.py             # 或 run_all.m 等总入口
├─ config/                   # 参数、随机种子、实验配置
├─ outputs/
│  ├─ tables/
│  ├─ figures/
│  └─ logs/
└─ AI工具使用详情.pdf        # 使用 AI 时按 2026 规则提供
```

不必为三天比赛追求大型工程，但必须让评阅者知道从哪里开始、哪些文件是输入、怎样得到论文中的表和图。

## 论文公式与代码的对应

建议在 README 建立一张短表：

| 论文位置 | 代码入口 | 输入 | 输出 |
|---|---|---|---|
| 式（12）参数拟合 | `src/problem1/fit_params.*` | `data/raw/...` | 表 3 参数、图 4 残差 |
| 式（20）优化模型 | `src/problem2/optimize.*` | 表 3 参数、配置文件 | 表 6 方案、求解日志 |
| 第 6.2 节敏感性 | `src/validation/sensitivity.*` | 基准配置 | 图 9、结果 CSV |

这样能及时发现论文目标函数与代码适应度函数不一致。

## 参数、随机性与结果保存

- 参数集中放在一个配置文件，记录单位和来源；不要在五个脚本里复制常数。
- 随机算法固定种子并运行多次；保存每次的目标值、可行性、耗时，而非只保存最佳图。
- 输出表保留完整精度，论文再按有效数字展示；不要从图上手抄结果。
- 保存求解器状态、版本、终止原因和约束违背量。
- 图由脚本从结果数据自动生成，文件名与论文图号相对应。

## README 最小模板

```markdown
支撑材料说明

环境：Python 3.x / MATLAB R20xx / 求解器版本……
入口：运行 `run_all.*`；预计耗时……
输入：`data/raw/` 为题目附件，`data/external/` 来源见……
输出：论文表 3、图 4 分别生成到……
随机性：种子为……；重复……次；汇总规则为……
已知限制：……
```

## 2026 规范对应

`[官]` 2026 论文格式规范要求附件列出支撑材料文件清单，并提交所有完整、可运行的源程序；使用 Excel、SPSS 等交互式软件时，也要提供完整可执行命令。源码不完整、不能运行或结果与论文不一致，可能被取消评奖资格；没有程序也应明确说明。

`[官]` 支撑材料还应包含自采数据和过长的中间结果表，并保持匿名。压缩包应为 RAR/ZIP，大小不超过 20 MB。最终以官网和赛区系统提示为准。

## 代码附件自检

- [ ] 有总入口和不超过一页的 README。
- [ ] 原始数据、中间数据、最终输出分开。
- [ ] 参数、单位、来源和随机种子集中管理。
- [ ] 论文关键表图可由代码重建。
- [ ] 每个求解器记录版本、状态和终止条件。
- [ ] 不依赖个人绝对路径、未提交文件或手工点击记忆。
- [ ] 从干净目录按 README 实跑一次，结果与论文一致。
- [ ] 文件名、注释、元数据和输出中无学校、姓名、队号等身份信息。
