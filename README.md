## 工作区

| 路径 | 用途 |
|---|---|
| `Pr/` | 模型说明、适用范围、验证档案与假设备忘录 |
| `src/microgrid/` | 唯一主模型实现 |
| `tests/` | 因果性、路由、物理约束、结算与时间映射测试 |
| `tools/` | 通用运行、严格模板导出和核验入口 |
| `tools/experiments/` | 预测评估、历史诊断和敏感性试验 |
| `data/`、`question/` | 原始附件与题目，只读 |
| `outputs/` | 分版本结果、轨迹、账本和关键核验记录，见其索引 |
| `skill/` | 原有建模与论文写作参考资料 |

```powershell
.venv/Scripts/python.exe -m pytest
```
