# 问题四经济性修正与两周复测

2026-09-12。用户要求减少预留、以降低实际电费为主要目标。最终版本为`report-economic-reserve-v5`，用于问题4-2/4-3的auto/report_blend。旧v3及本轮中间试验v4的输出与源码压缩包保留，不覆盖。

## 1. 高电费的账务与算法原因

依据旧v3完整轨迹和执行账本独立复算，报告行均为1月8—14日、1008个十分钟区间。4-3费用743350.636316元，4-2为550992.114964元。以下分解互不重叠，总差192358.521352元：

| 费用分项 | 4-3相对4-2变化/元 |
|---|---:|
| 全部普通购电O+A按基础价计费 | +127040.921314 |
| 调整增购A额外0.5倍溢价 | +66807.297410 |
| 紧急购电费 | -3444.611913 |
| 调减违约费 | +1954.914541 |

4-3实际普通购电847348.165709 kWh，其中增购133501.350871 kWh；弃购电41564.499265 kWh。两分支实测光伏均258074.303833 kWh，4-3仅利用24789.989471 kWh，利用率约9.61%。光伏被大量弃置，未实现其应有的供电替代。上述账务分解直接解释费用差；不能把基础价费用差全部归为数量效应，其中也含时段价格与购电时机变化。

代码机制支持以下原因：

1. 旧目标包含完整基准紧急费用，再叠加完整压力紧急费用及单段备用缺口的5倍价惩罚。同一潜在短缺被重复强调，使1.5倍价增购在优化器看来仍显得便宜。压力场景不会实际发生的部分也按完整紧急成本推动购电。
2. 年初周周期预测尚未具备历史时的误差，被混入后续已具备周历史的预测误差模型。1月8日日初只有5条完整历史误差路径，0.90次序统计量近似取最大值，压力附加量达22248.513990 kWh；少样本10%负荷下限又抬高预留。
3. 4-3每个合法节点可按更新后的保守压力需求增购，而购入后即使实际负荷不需要，仍需支付增购溢价。实际执行只能在满足设备边界后弃光或弃购电，无法追回已成交成本。
4. 旧4-3报告周19次候选调减检查均未拦截，因此该周高费用不能归因于调减拦截强行恢复购电。

## 2. 本次算法调整

- **降低冷启动预留：**成熟样本少于7条时，累计及单段技术先验由预测负荷10%降为3%。成熟经验分位仍为0.90，避免同时修改过多分位设定。
- **匹配预测训练阶段：**成熟期误差形成时刻必须不早于1月8日00:10，且整条误差路径在当前决策前已完成。前一周未建立周周期模型时的初始化误差不再作为后续成熟模型的长期备用样本。没有样本时只使用明确的3%先验，绝不借用未来实测。4-2自身尚处于首周时例外：此时保留当时成熟的初始化误差，避免冻结计划失去日内恢复机会。
- **消除重复风险定价：**保留完整累计压力路径的SOC、效率、功率约束，取消该模式重复叠加的单段备用缺口惩罚。基准与压力路径共享同一个普通购电计划。
- **用加权成本权衡风险：**通常优化目标为`普通购电及调减费 + 5×预测价×(0.8×基准紧急量 + 0.2×压力紧急量)`。4-2首周（决策时刻<1月8日00:10）使用基准/压力各0.5，到达该界限后恢复0.8/0.2；日计划不会因此在越权时刻重写。仍按既定弃购电优先级处理已成交过购。上述权重为经济性技术参数，不声称是校准后的概率。高价预购只有在其加权预期缺电损失足够大时才有吸引力。
- **保留交易与物理规则：**4-2日内冻结、4-3仅06/12/18调整，调减前仍检查至下一节点的供给能力，初始SOC6000仅在1月1日00:10设一次。原始费率、网电直供、真实账务及付费弃电规则不变。

实现中risk_penalty_yuan为相对完整基准紧急费用的加权校正，允许为负；两条路径的紧急量在总目标中的系数始终严格为正。此前v3曾发现系数降到零时会出现虚增基准紧急购电，本次通过权重范围0<w<1及专用回归防止复发。真实账单仍对实际紧急购电完整收取5倍价，不把风险校正计入结算。

## 3. 验证设计

相同附件、相同1月1日00:10初始6000 kWh，连续至1月15日00:10，共2016段；前1008段前置，后1008段检验。逐项比较旧v3与新v5各分支，不用旧4-2作为新4-3的唯一成本基准。

回归已通过：全部107项。覆盖旧问题兼容、未来信息隔离、风险权重缓存更新、无虚增基准紧急购电、取消重复风险、压力路径守恒、调减保护，以及仅4-2首周保留初始化误差的分支/时间路由。

最终v5两个分支各连续2016段完成，无不可行或跳过时段，物理、账务、版本路由与调减审计均通过。目标是实际总费用降低，同时公开紧急量、弃光/弃购电及首末SOC；不以紧急量为零作为优化目标，也不将这段开发回测解释为全年最优保证。

### 中间试验v4为何未直接作为最终版本

v4对所有阶段统一使用0.8/0.2，并完全排除第一周形成的误差。检验周4-2费用下降20.20%、4-3下降42.18%，弃购电分别降至918.83、923.78 kWh。但4-2前置周增加费用146909.22元，抵消检验周节省后，完整两周反而多35605.46元（+2.58%）。4-3完整两周节省345568.26元（22.39%）。因此保留4-3方案，仅修复4-2首周保护，形成v5再连续复测。该对照说明降低预留不能简单等同于所有阶段都少买电。

v4档案位于`outputs/问题四_经济性优化_两周检验_20260912/`，含完整轨迹、经济性对比JSON及当时源码包，明确标为中间试验。

### 机制核验与限制

- 新4-3检验周9次候选调减检查，1次拦截并恢复34.829722 kWh；全两周13次检查、4次拦截、恢复105.525280 kWh。每次恢复后的压力缺口不高于原有效计划。4-2无越权日内调整。
- 新v5检验周的误差样本均少于7条，属于小样本策略的短程检验；成熟期0.90经验分位及3%/权重的泛化能力需在未参与本次调参的月份验证。
- 基础预测没有在本轮重新拟合为未来真值。负载/光伏MAE与v3一致，主要变化来自购电与风险算法；无单独消融试验，不能把总节省精确分摊给每项代码修改。
- 所有购电实际费用含原计划、1.5倍增购、5倍紧急及调减罚金。风险加权校正不进入真实账单，压力松弛为正不等于实际紧急购电。
