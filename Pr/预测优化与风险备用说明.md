## 预测方法

负荷以目标时刻前7、14、21、28天同一时刻的成熟样本加权，权重依次为0.70、0.15、0.10、0.05。可用样本权重重新归一化。最近18个已完成十分钟区间相对上周的偏差中位数为短期修正，乘以`exp(-预测提前分钟/360)`；预测最终截断至非负。窗口延伸到明天时，使用明天对应的星期样本。

历史光伏采用最近7日已完成同刻样本。允许附件3的分支把原预报F和历史预测H组合为`aF+bH`，a、b通过非负最小二乘估计；训练资料是过去28日同一发布时刻的预报与随后已完成的24小时实测。正则项向`a=1,b=0`收缩，强度为`max(1,0.02*sum(X**2))`。配对天数不足7时沿用原预报。未被已发布预报覆盖的次日部分用历史预测。

## 由误差设置备用

形成预测的时刻为a，目标时段为t，联合误差为：

`e[t|a] = (实际负荷[t] - 实际光伏[t]) - (预测负荷[t|a] - 预测光伏[t|a])`。

正值代表净负荷被低估。使用过去28日、相同合法决策时刻形成的完整误差路径。只纳入其全部目标区间结束不晚于当前校准时刻的路径；负荷与光伏保持配对，不作独立性假设。

有m条历史路径、目标分位q=0.90时，选第`min(m,ceil((m+1)*q))`小的观测值作为上侧统计量。逐段正误差的上侧值记作M[t]。对每条路径，从t累加至下一次允许改普通购电的时点前，取正向累计缺口最大值，再跨路径取相同次序统计量，得到B[t]。

- 逐段净负荷上界：`U[t]=max(0,预测负荷[t]-预测光伏[t]+max(0,M[t]))`。
- B[t]是送达侧累计备用kWh；电池需要保留的相应存量为`B[t]/0.9`。
- 问题2、4-2的累计区间截至次日00:00；问题3、4-3截至下一次00/06/12/18。
- 校准在这些合法节点刷新；十分钟滚动规划使用相应的剩余路径，点预测仍按当下成熟信息刷新。

这同时保留了负荷和光伏误差的相关性、连续几小时偏差的累计影响，以及不能随时调整普通购电的限制。单段分位和累计路径检验是不同指标，不能将两者混称为供电保障率。

## 规划约束与经济权衡

设S≥0为窗口最大累计备用缺口，v[t]≥0为逐段供电能力缺口，均以送达侧kWh计：

```
0.9*(E[t]-1200) + S >= B[t]             （未来边界，初始实测SOC不倒改）
h[t] + 750 + v[t] >= U[t]               （放电功率）
h[t] + 0.9*(E[t]-1200) + v[t] >= U[t]   （可用电量）
```

新购电决策另满足`h[t] <= 预测负荷[t] + (10800-E[t])/0.9`，防止在没有储存空间时用循环损耗“吸收”额外备用购电；冻结的h不重新套新上限以免越权改约或导致无解。原有母线平衡、SOC递推、充电功率与弃电规则继续生效。

先最小化不可避免的弃购电；其次最小化：

`真实预测电费 + 5*平均预测电价*S + Σ 5*预测电价[t]*v[t]`。

最后才作优先利用储能的同成本选择。累计备用惩罚只对最大缺口计一次，逐段缺口单独计价；两个风险指标可能重叠，惩罚是透明的调度代理目标，不是新增的实际收费，也不是严格的期望损失公式。实际账单与result仍只按原计划、增购、紧急购电和合法调减事件计算。

保留松弛变量是为了诚实表示“当前设备或冻结合同无法提供目标备用”，而非保证90%必然实现。若备用需求超过8640 kWh的最大送达侧可用储能，会明确出现容量不足；模型仍可通过普通购电提高逐段能力，无法补足的部分由执行层按既有规则紧急购电。

## 验证边界

预测检验覆盖2025年2月1日00:00至2026年1月1日00:00，按自然日划分，区别于result从00:10起的日期行。每次训练和校准均遵守当时的信息截止；由于建模设计已查看本数据，这属于因果滚动历史检验，不是未接触的未来独立留出集。

调度对照覆盖问题2、3、4-2、4-3的2月6—7日和12月8—9日；各版本从该分支原全年轨迹的同一个实测SOC出发，随后连续运行两天、每十分钟重算。这个重启仅由命名验证实验允许，主模型仍强制从1月1日00:10、6000 kWh开始全年连续运行。末端SOC自由且单独披露，因此短期账单差额不能直接解释为库存相同的纯节省，更不能外推全年节省。

最终指标见输出目录中的`forecast_metrics.json`、`forecast_daily.csv`、`dispatch_metrics.json`及各对照运行的轨迹。新规则尚不能用此前生成的旧全年Excel来评判；如需新版全年结果，必须重新完整运行。
