# 模型优化定稿与验证档案

更新日期：2026-09-12。本文件为当前实现、参数和验证状态的总入口；四问数学规范负责完整约束，历史报告记录当时结论。阶段性描述冲突时，当前适用范围以本文件为准，不能用旧文中的“尚未求解”判断现在状态。

“定稿”指已确认的设备、交易、时间口径和已实施预测算法的说明。问题四已接续完成三个机制修正及经济性调整，当前版本与验证范围见 [问题四经济性修正与两周复测](问题四经济性修正与两周复测.md)。[v3两周检验](问题四三项修正与两周检验.md)保留为上一版诊断，不能以短程结果代替全年验证。

## 1. 已确认的主模型口径

1. 外网直接向小区供电，储能不是外网入小区的必经路径。仅电池存入、送出部分计效率；光伏可供负荷、储存或弃光。
2. 每段10分钟，输入平均功率除以6得到kWh。SOC范围1200—10800 kWh；单段存入、送出上限各750 kWh，充放电效率均0.9。允许同时充放电，损耗只计一次。
3. 问题二至四跳过缺失的1月1日00:00—00:10，从00:10以6000 kWh连续递推，2月1日不重置。问题一为单日循环，首末6000 kWh。
4. 每段以因果点预测联合优化当天剩余时段和次日，次日前瞻不提前成交。问题2/4-2的日初普通计划冻结；问题3/4-3仅自然时钟06、12、18点可调整。十分钟重算不等于十分钟可改普通购电。
5. 原计划标签O、增购标签A，执行量h=O+A。调减先扣A再扣O，恢复记入A。实际费用为价×O、1.5倍价×A、5倍价×紧急量，另加调整发生时0.5倍价×取消量的违约费。
6. 不可避免的已付费过购允许弃置，仍计购电与费用。规划先减少弃购电，再最小化预测费用与经验风险惩罚，同成本时优先利用储能。容量或充电功率上限均可能导致弃电，不能把所有弃电解释为满容量。
7. 问题四只用当时成熟的历史预测未来价，真实费用按区间实际均价结算；不读取附件4未来真值作规划。

物理平衡：`h+u+G-r+q_dis=D+q_ch/0.9+w`；储电递推：`E_next=E+q_ch-q_dis/0.9`。u为紧急购电，r为弃光，w为已付费弃购电。

## 2. 已实施并经过检验的预测优化

### 负载预测

目标时刻前7、14、21、28天成熟同刻样本，权重0.70、0.15、0.10、0.05，可用项重新归一化。最近18个已完成区间相对上周同刻的差值中位数作近期修正，按 `exp(-提前分钟/360)` 衰减。截断非负，跨日使用目标日期对应星期。缺少历史时使用成熟同刻统计或有来源的附件1先验，不能用未来实测补历史。

### 优化光伏：report_blend

1. 最近7日同刻成熟光伏建立十分钟形状，在报告小时内分配六段，形状全零时均分。仅此步保持原报告小时总量。
2. 按发布时间和目标小时做乘法校正；最近28日、半衰期7日、过原点加权回归向系数1收缩，强度相当于2个有效日。至少7个成熟日，系数限制[0,2]。
3. 校正报告与历史预测动态融合；过去14日按原信息截止重建预测误差，半衰期7日，向历史预测收缩4个有效日，权重限制[0,1]，至少7个成熟日。
4. 节点之间使用本次发布后最近6个已完成区间的残差中位数修正，按 `exp(-提前分钟/120)` 衰减；原预测为零的夜间不引入白天残差。
5. 只读当前已发布的00/06/12/18点报告；覆盖之外用历史预测。校正、融合会改变报告总量，最终预测不再等于原报告小时总量。

窗口、权重、收缩、截断属于技术假设，不是题面参数。实现为 `src/microgrid/report_forecast.py`；完整参数和选择过程见 [光伏预报分时校正与两月检验](光伏预报分时校正与两月检验.md)。

## 5. 旧版经验备用及替代范围

从当时成熟的最多28条联合误差路径提取0.90上侧次序统计量。单段上界反映净负荷低估；B[t]取从t至下一合法调整节点的正向累计误差峰值。LP采用 `0.9*(E[t]-1200)+S>=B[t]`，另约束普通购电加放电能力达到单段上界，对最大备用缺口S及逐段缺口作软惩罚。

这些惩罚仅为规划偏好，不进入电费，不是90%供电保证。最新诊断发现：随剩余时段递减的B[t]没有正确保护从购电决策起此前误差累计消耗的电量。提高分位数本身不能证明修复。冻结购电后虽能滚动看到SOC下降，也可能已经失去普通增购权限。

实际运行过的公式保留在 [预测优化与风险备用说明](预测优化与风险备用说明.md)。问题二、三及显式pooled仍沿用该实现；本轮仅问题四report_blend替换为累计压力路径，完整公式、技术假设和限制见新修正说明。
